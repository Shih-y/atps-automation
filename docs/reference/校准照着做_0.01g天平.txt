用现有0.01 g天平做清水初调｜照着做
更新：2026-11-10

现在可以完成两件事：测本机充水状态下每圈出水量；把清水“5剂一组”的平均交付量调到每剂约0.20 mL。全程用现有清水、0.01 g天平、10 mL小瓶和废液容器，不需要增加硬件。
这套清水初调不直接签核PEG或其他母液，也不证明每一剂都合格。先得到可信的实测数，再决定参数；不要把默认45步当成已经准确的0.20 mL。

一、放好管口，打开清水向导

1. 打开控制网页，连接COM6，在“第一次使用：清水称重校准”中操作。泵地址1、阀地址2沿用现值，不改地址。
2. 15口支管放入清水，管口保持浸没；16口接清洁空气。C端悬在废液容器上方，保持通气，不插入废液。
3. 记录清水情况、温度（如已知）、瓶口和管口位置。各轮保持装配、液位范围和管口高度尽量相同。称重时小瓶外壁应无水滴，液体不要倒到天平上。
4. 默认清水密度1.0000 g/mL用于初调近似换算。若使用按水温确定的可靠密度，可填相应值；所有计算用同一轮实际填写的密度。
5. 去皮法：称空瓶并去皮，取下收水，再放回称净质量。也可记录收水前、收水后质量，两者相减；输入网页的是差值，不是带瓶总质量。

二、先把整条水路灌通

1. C端仍对准废液，点击“15口清水灌管”。本版动作是20原生圈、50 rpm，转动约24 s，动作超时40 s。
2. 看实际液头和C端。需要看到清水确实从C端连续流出；停泵本身不表示已经灌通。
3. 已见连续出水，再点“已看到C端连续出水”。若未见，先看15瓶是否有水、管口是否浸没、液头是否前进、接头是否漏气或堵塞；确认仍在正常前进后才能再做一个有限灌管动作。出现异常就停下检查，不按次数假定成功。
4. 这一步只确认水路贯通，不把该观察记成残水或交叉污染合格。

三、测每圈出水量：5圈一次，共3次

1. 拿现有空10 mL小瓶去皮，或记下收水前质量。
2. 把小瓶放在C端下面。C端保持悬空，不能浸入瓶内收集的水；不要因换容器拉动软管或改变其固定位置。
3. 点击“瓶已去皮，C端收集5转清水”。动作是5原生圈、50 rpm，转动约6 s，超时20 s；厂家参考量约4.5 mL，实际以称量为准。
4. 停泵后按一致的短等待收完仍属于本次出水的滴液，再把C端对应位置恢复到废液容器上方。称小瓶净质量，填“第1次净质量”。不要让C端滴到台面，也不要把额外冲洗水混入称重。
5. 倒空、重新去皮，按相同方式再收2次，分别填写第2、3次。三次之间保持水路充满水，不进行16口空气吹扫。
6. 点击“计算并保存每转出水量”。程序保存三个实测质量，不用填假定值。

计算：每次mL/圈=净质量÷密度÷5；三个结果取平均。
例子仅说明算法，不可抄作实测记录：4.50 g、4.45 g、4.55 g，密度1.0000，平均0.900 mL/圈。
这个系数属于充水、50 rpm、当前软管装配条件；不能直接拿它把空气追送或PEG换算成准确体积。

四、排出公共管内连续水柱

1. 确认C端已重新对准废液容器，出口悬空。
2. 点击“16口空气吹扫”：15原生圈、60 rpm，转动约15 s，动作超时30 s。
3. 停泵后看公共管和C端。有连续水柱时继续检查，必要时再做一次有限吹扫。只有确实看不到连续水柱、C端没有悬滴，才点“已无可见连续水柱，C端无悬滴”。
4. 这只表示可以继续本次清水试验，不表示管壁已经干燥。15口来源支管保持清水浸没，16口吹扫并没有把关闭的15支管也清空。
5. 随后的CW追送会从C端吸气。因此追送前仍要保持C端清洁、悬空、避开废液飞溅，不得将其留在废液液面下。

五、先只送1剂，确认水确实到了所选瓶

1. 选择用于称重的样品口1—6，将对应样品支管放进清洁小瓶，瓶盖保持通气。记录并固定管口高度；不要用手持管口、随时改变位置的方式比较各轮数据。
2. 首轮保持吸取45步、5 rpm；追送300步、10 rpm。估计转动分别约2.7和9 s，另有切阀与通信时间。
3. 点击“只试送1剂清水”。观察液段在A内形成、随后经样品支管送入瓶；确认未把液体吸入泵头。
4. 确实看到本次清水进入所选瓶，再点“已看到本次清水进入所选瓶”。动作结束或管内有液体，不等于液体已到瓶。
5. 没到瓶、只到一部分或量明显很小时，先看液塞停在哪里、是否漏气、是否追送不足。需要时有依据地调追送步数并重新试送；不能因为称重小就直接成倍增加吸取步数。更换样品口或追送步数后，要重新完成这一剂观察。
6. 本次单剂用于核对路线和追送。不要把它加入后面的5剂组质量，也不要用0.01 g天平这一条单剂读数宣称0.20 mL精度已达标。

六、5剂一组，共称3组

1. 等程序本次动作及末尾排水结束。倒掉刚才试送的水，将称重瓶倒空、去皮，或记录本组开始质量。不要重新冲洗样品支管，也不要把其中液体特意排空来改变条件。
2. 把同一支管放回同一位置。移动小瓶称重时保持管端固定，避免碰撞、外壁挂水带入，以及改变管口高度；每组恢复相同瓶位。已经用湿的样品支管仍算“使用后支管”，倒空瓶子并不会让它变成“首次空管”。
3. 先观察上次试送后的公共管与C端，点击“上次试送后已无连续水柱，C端无悬滴”，再点击“瓶已倒空并去皮，连续试送5剂”。一组目标总量约1.00 mL，按密度近似1.0000时约1.00 g。
4. 程序在每剂后使用16口空气排水，包含本组最后一剂后。这个纯水初调不在剂间追加15口水洗，因为来源和交付液都是同一清水。它不替代以后不同母液之间的15水洗＋16排水正式流程。
5. 等整组停止，保持一致的收集结束方式，称这一组净质量，填“第1组（5剂）净质量”。只填实际读数，不填1.00的目标值。
6. 倒空并重新去皮，保持同一使用后样品支管和管口位置。每组后都观察并再次点击“上次试送后已无连续水柱，C端无悬滴”，再做第2、3组。每组各5剂，三组共15剂；不能把三个组的累计质量当三个独立净质量。
7. 初始45/300步时，每剂吸取和追送约11.7 s，随后空气排水约15 s；每组纯运动约5×26.7=133.5 s。实际还需切阀与通信时间。收集称量和观察所用时间另计。
8. 点击“计算并保存组平均交付量”。记录三个组质量、步数、样品口和备注，以便下一轮比较。

七、怎样看结果、怎样改步数

每组平均每剂体积=该组净质量÷密度÷5。
三组总平均每剂体积=(第1组质量+第2组质量+第3组质量)÷密度÷15。
下一轮建议吸取步数=本轮吸取步数×0.20÷本轮平均每剂体积，再按整数步处理。

例子仅说明算法：三组0.90、0.92、0.91 g，密度1.0000，则平均每剂0.182 mL；旧45步×0.20÷0.182≈49.45步，整数建议约49步。
比例修正只是下一轮候选。液塞变长、气体压缩和管壁残留可能让关系不完全成比例，所以采用后必须重新收集3组。
报告不会自动开泵，也不会自动改追送量。只有点击“采用建议吸取步数，准备下一轮”，才将建议填入吸取栏；追送步数保持原值。
不要同时把吸取和追送乘同一个比例。追送的任务是让已有液段完整到瓶，并非决定母液吸取体积。
如果出液为零、很少、时有时无，或比预计偏低很多，先回到单剂观察解决输送问题；此时不采用公式给出的巨大吸取步数。
保持三组在相同步数下完成。中途改过吸取、追送、瓶号或管口位置，应重新开始一轮，不能把不同条件拼成三个组。

八、0.01 g天平能说明什么

单剂0.20 mL清水约0.20 g，天平0.01 g的一格已占5%；5剂合计约1.00 g，一格约占1%。这说明分组称重更适合平均量初调，并不意味着天平实际准确度就是1%，也不能由显示位数推定误差。
三组得到的“组间RSD”只说明这些5剂合计结果之间的变化。它不能揭示一组内是否一剂多、一剂少，不能替代单剂重复性。
水膜可能增加下一次称到的总水，使用后样品支管也可能留水。纯水条件下，天平无法区分本次吸入的水与前次残留带来的水。这是保持同样顺序、管口高度并完整记录的原因。
仅凭这台天平，不能可靠证明0.005 mL残水门槛：该水量约0.005 g，小于一格；0.20 mL的1%为0.002 mL，同样小于一格对应的水量。
当前能做的是完成水路贯通、实际水流量测量、平均剂量初调和明显输送异常排查。不要为了让正式档案通过而填写虚构的残水、污染或单剂读数。

九、进入正式母液实验前，哪些仍要分别验证

正式0.20 mL档案仍要求至少10次独立的完整“吸取→停泵切阀→追送到瓶”测量，以及至少3次残水空白、3次交叉带入记录；本版筛选线为均值0.19—0.21 mL、单剂RSD≤5%、残水≤0.005 mL、交叉带入≤1%。5剂一组的初调报告不能代替这些证据，现有粗分度天平本身不足以证明全部门槛。
正式首次条件需要实际清洁、空的样品支管；用湿支管配一个倒空瓶仍属于使用后条件。本次三组试验属于使用后支管条件，不能写成3次首次空管重复。
PEG或其他母液必须用各自液体、浓度、温度和装配验证。收集液总质量可能包含母液、清洗残水或旧液；不能直接除以母液密度就冒充“实际母液体积”。需要能区分组分的分析方法，或有严格证据证明所称液体只有该单一液体；不能假设残水为零。
不同母液的正式轮换仍按已验证的清洗和排水流程执行。本向导省去纯水剂间15水洗的做法，只用于这次同一清水初调。
鼓泡、消泡和成像等待另行评估；本向导没有用0.01 g称重结果证明混合已经充分。
