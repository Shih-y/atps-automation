# 当前加料与多瓶操作

## 先分清瓶号和阀口

| 瓶号（照片、配方和队列使用） | 实际阀口 |
|---|---|
| 1号瓶 | 1口 |
| 2号瓶 | 3口 |
| 3号瓶 | 4口 |
| 4号瓶 | 6口 |
| 5号瓶 | 7口 |

选“2号瓶”时，程序应送到阀3口。手动台的“阀口”直接表示硬件口号，选3口就是3口。照片ROI继续编号1—5，不改成1、3、4、6、7。当前没有第六瓶接管依据。

## 只想按毫升配一瓶

在“设备与校准”的“单瓶配方”选择目标瓶，填写各来源需要的mL，不用的来源填0。选择是否勾选“本瓶完成后清洗并吹扫”，点“预览各来源标定与步数”，再点“开始整瓶配方”。

- PEG14口：原1 mL指令共吸取300步，现场实收0.42 mL。临时比例为0.0014 mL/步，即步数=请求mL÷0.0014，最后四舍五入为整数。1 mL为714步，约3.57圈，吸取5 rpm；追送原生30圈、60 rpm，约30秒。
- 各来源一次吸取、一次追送，取消0.8 mL自动拆段。不会为了赶时间自动提高吸取转速。超出单次有限动作时间或已保存标定范围时，整份配方不启动，并显示原因。
- 10—15口的手动mL加料追送全部统一为原生30圈、60 rpm，理论运行30秒、超时46秒。不会把“30圈”误写成“30步”。吸取转速和比例仍按原来源参考。
- 本瓶全部加完后，沿用设定的混合动作。勾选清洗时：切15口，CCW朝C端废液方向引入约1.5 mL清水，然后切16口，以CCW吸入空气、继续朝C端废液吹扫30圈/60 rpm。取消勾选时，这两步都跳过。混合与清洗是不同动作，清洗选项不取消混合。
- 末尾清水按C端5圈称重参考换算：平均0.915333 mL/圈，约328步、1.64圈，默认50 rpm。它不计入样品配方。样品端“45步约0.15 mL”不能用来计算C端清洗。
- 单独“执行已预览的单来源加液”只做吸取和追送，不自动混合或清洗，便于组合调试。独立的清洗、空气吹扫、原始泵阀按钮仍可手动使用。

当前公共软管91 cm、内径3.2 mm，几何容积约7.32 mL。引入1.5 mL水本身不保证水从C端流出，也不证明整管已清洗；所以清洗后继续用16口空气推向废液。30圈按旧清水参考对应约27.46 mL液体排量，仅用于选定有限吹扫圈数，不能把它当作实际空气量或排净证据。程序记录“吹扫动作完成、干燥未验证”。

**吹扫结束后看两处：**公共软管内没有可见连续水柱；C端没有明显悬滴、没有飞溅。还看见水就点“清洗与吹扫”中的“16口空气吹扫”再补吹一段（独立按钮沿用15圈/60 rpm）。16口吸气端保持清洁，C端悬空对准废液，不能浸入废液。没有传感器，程序不能保证无水膜；交叉污染和真实残水量仍需实验验证。吹扫中点立即停止会取消后续瓶，不会自动重放中断配方。

各来源有适用的现场体积标定时，吸取比例优先使用该标定，不再叠加PEG的2.381倍修正。手动mL追送统一覆盖为30圈/60 rpm；旧参考的追送参数保留在记录中，若不同则显示条件改变、交付量待复测，不把旧参考自动视为新条件的精度依据。来源体积标定表单默认原生整圈30圈、60 rpm、超时46秒。PEG现场试送可填写吸取714步、5 rpm、超时62秒；其他来源填写其实际试送吸取步数。收集实际体积再录入。没有实测密度时，不要把称得的PEG克数直接当毫升。跨剂量、跨瓶共用标定需要相应依据。

## 多瓶配方怎么用

**只按毫升配多瓶：直接在“设备与校准”使用“多瓶毫升配方”。**

每行选择瓶号，填写10—15口各要加入多少mL，不用的来源填0；整行都是0就跳过。每瓶只填一行。可以先预览，也可以直接开始整批。“每瓶完成后清洗并吹扫”独立于单瓶开关，默认勾选，统一用于本批所有瓶。程序按表格顺序逐瓶加料、混合；勾选则每瓶随后清洗和吹扫，取消则都跳过。来源之间不清洗、不吹扫。不要求项目、质量分数或g/步标定。它使用当前手动体积参考和来源体积标定，不能因此认定真实交付精度已验证。页面刷新不重新启动，停止后未开始的瓶不再执行。

例如：第一行选1号瓶，14口填1、13口填0.3、15口填0.5；第二行选2号瓶，再填第二瓶的量。其余行保持0，选是否清洗后点开始即可。表中15口mL是加入样品的水；勾选清洗时每瓶末尾朝废液清洗的1.5 mL由程序另加，不计入样品配方。

**需要质量分数配样与图像/主动学习项目时，才使用下面的正式实验入口：**“实验设计”与“运行监控”，按质量分数和总质量配样，与上面的手动mL调试是两条入口。

1. **准备瓶子。** 在“运行监控”找到“排队、重配与换瓶”，逐一选实际已换好的瓶位，勾选“我已放入干净空瓶”，点“确认换好干净空瓶”。只有真换了空瓶才这样记录；程序不会自动倒空或洗瓶。
2. **准备本批母液及标定。** 在“设备与校准”保存PEG、所用盐、水的批次和浓度，完成各来源的质量交付标定。正式自动配样需要各自的g/步依据和适用瓶位。PEG临时mL修正不能冒充g/步；缺依据可以预览，但不能自动投料。接管映射改变后须核对标定适用性并创建项目新版本，旧记录保留。
3. **建立项目。** 到“实验设计”，填项目名称，选一种盐，填总质量、已确认的安全质量上限、观察时间，点“建立项目”。每个项目是PEG＋一种盐＋水。研究另一种盐要建另一项目。
4. **加入想做的样品。** “配样方式”选择“独立配样：干净空瓶”，填PEG%、盐%、总质量g。“独立重复数=5”表示同一配方做5瓶；若要5个不同配方，就每次重复数填1，预览并加入队列，改配方后再次预览、加入，共做5次。按钮是“预览全部独立样品”→“将预览的独立样品加入队列”。预览显示不可执行时先处理列出的原因。
5. **开始当前项目。** 回“运行监控”，确认项目、样品数量和预约瓶位，点“开始当前项目”。泵阀逐瓶执行，各瓶独立计时静置；1号瓶静置时可配2号瓶。不要在静置期间手动扰动同瓶。
6. **看照片并复核。** 保持相机和程序工作，到“图像判相与复核”按样品查看照片，标单相、双相或待确认。看不清就选待确认。默认人工复核后才允许同瓶定量续加；其他瓶可以继续。

“暂停后续任务”让已开始的一瓶继续完成，只暂停后面的任务。“立即停止”停止当前动作并保留中断记录；不能点开始就把整份中断配方重新加一遍。当前瓶加了多少无法确认时，应换瓶重配为新样品。

## 本次方法变更的适用范围

PEG体积比例修正、每来源一次加料、统一30圈/60 rpm追送、可选末尾清洗和吹扫属于手动mL配方。正式自动质量实验继续使用项目冻结的来源标定、分段范围与清洗/吹扫方法；这些科学方法参数不能在没有新标定时静默替换。原始手动泵阀和历史清水称量向导保持可调参数，保存的原标定记录不改写。瓶号→阀口映射统一用于手动样品加料和自动实验，原始手动阀口控制保持物理编号。

本说明不声称已完成新方法的真实加料精度、清洗残水或交叉污染验证。
