# 液路控制与实时监视

点击顶部「液路控制」进入新页面。左侧看接管，右侧操作，下方看五瓶任务、动作时间线和最近事件。原来的「设备与校准」仍有单瓶、多瓶毫升配方、预充、清洗和校准。

## 先认清图

- 1—5号瓶分别接阀1、3、4、6、7口。2、5口保留手动调试；8、9口不启用。
- 来源10/11/12/13/14依次为柠檬酸三钠、硫酸铵、硫酸钠、磷酸氢二钾、PEG；15为清水，16为空气。
- 中心C是阀公共口。公共软管穿过唯一一台泵后到悬空废液端。C不是第17口；样品瓶没有独立泵出口。
- 图表示连通关系，不表示实物摆放比例。选中的通路着色；移动短线表示估计流向，不表示已测到液段，也不能证明液量或洗净程度。

## 手动做一个动作

1. 在「设备与校准」连接设备，或在设备连接区域进入模拟工作区。
2. 回到「液路控制」，选阀口。只想转阀就点「仅切阀」。右侧先显示目标口，确认后才显示确认口。
3. 要转泵，填转向、rpm和整数圈数。下方会显示流向和标称耗时。修改输入不会动作，点「按参数运行」才执行。
4. 当前接管中CCW为所选口流向公共管和C端；CW为C端反向送向所选口。页面根据配置显示方向。
5. 「立即停止」使用同一套优先停止处理，保留连接；只有读回确认后才写「已确认停止」。不要将软件按钮当成设备实体急停。

有自动批次运行或手动动作占用泵阀时，新页的手动按钮暂时不可操作，避免同时发两个动作。仅查看页面或点瓶卡片不会执行泵阀动作。

## 单瓶、多瓶怎么用

点右侧「单瓶 / 多瓶配方 →」回到设备与校准，按瓶填来源口mL，选择是否末尾清洗，启动后可返回液路页观察。追送仍按保存的方法；本次界面改版不改变真实设备加料参数。

五瓶卡片显示各自记录。正式实验从自己的样品编号读取配方、已完成指令和采用组成；其他瓶静置时不会阻塞当前瓶配液。没有记录不代表瓶内为空。动作完成数不是实际交付质量。静置时间从记录的停气/混合结束时刻计算。

## 模拟计时

模拟与实机工作区数据和控制令牌分开，模拟不会打开真实串口。模式入口位于设备连接区域，顶部和底部常驻状态栏不显示模式；模拟网页标题和导出仍标记来源，避免误当成真实实验。

| 指令 | 模拟泵运行时间 |
|---|---:|
| 60 rpm，30圈 | 30秒 |
| 30 rpm，30圈 | 60秒 |
| 60 rpm，2圈 | 2秒 |
| 5 rpm，45步 | 约2.7秒 |

采用1倍时间，不加速演示。原生圈指令按 `圈数×60÷rpm`；步指令采用现有约200步/圈的工程依据。正常配方中的等待、观察计划也按原时间执行。

阀切换暂按0.5秒工程估计，可在配置的 `simulation.valve_switch_s` 中记录实测值。完整任务还受实机机械和通信延时影响，不能承诺与实物逐毫秒相同。停止可中断当前计时，刷新页面、断开后重启不会自动重放加料。

## 验证范围

软件测试检查模拟计时、停止、数据隔离、阀目标/确认、瓶口映射、正式样品信息及窄窗口布局。没有启动真实加料；实际母液回收量、残水、飞溅和分相时间仍以实测为准。
