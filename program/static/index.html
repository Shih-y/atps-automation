第一次操作顺序

  1. 连接设备，打开右侧“清水称重校准”。
  2. 15口灌管，看到C端连续出水后点击对应观察按钮。
  3. 每转出水量已内置保存，跳过重复称重；需要时展开可选重新校准。
  4. 16口吹扫，观察公共管内没有连续水柱。
  5. 选一个样品口试送1剂，确认清水确实到瓶。
  6. 用0.01 g天平每组称5剂，共3组；软件计算平均量和下一轮吸取步数。
  7. 清水校准完成后，再分别验证实际母液；正式实验使用下方母液档案、加料和成像流程。

已验证自动队列在开始前确认一次；运行期间全程观察，异常立即停止。没有液位、气泡或压力传感器，程序不能代替现场观察。

2引液与清洗复位

冲洗水从15口进入，向废液端排出；停泵切到16口后，继续朝废液方向抽吸空气，推动公共管内液体。通气不等于完全干燥，复位必须符合已验证的残水条件。

尚未选择

默认用20步、2 rpm靠近标线；液头尚远时可选择1整圈粗引液。整圈模式切换后预填10 rpm、30 s超时，可按现场调整。每次脉冲后观察液头，不能把抽气量当成母液体积。未验证吹扫状态下允许试验引液，不授予正式定量资格。

管内状态

样品管里原有的空气不能记为必然带入的水。已经使用的管路也不会自动变回初始空管。
