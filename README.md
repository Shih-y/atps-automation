# 双水相配液与图像记录平台

[![Windows tests](https://github.com/Shih-y/atps-automation/actions/workflows/tests.yml/badge.svg)](https://github.com/Shih-y/atps-automation/actions/workflows/tests.yml)

通过本地网页控制润泽 LM60A 蠕动泵和 SV07M-20P 十六路切换阀，用于双水相配液、清水称重校准、逐瓶鼓泡以及图像采集和判相记录。

本仓库已同步 **2026-11-12 的实机交付版本**。默认使用真实设备和自由调试界面；软件测试中的替身只用于测试，不是网页的模拟模式。启动程序和点击连接都不会自动转泵。

本次更新：泵阀状态与手动控制放在同一卡片；指定毫升一次吸取、一次追送；额外混合由用户最后点击；来源硬管预充改为 6 圈后直接吹扫；**立即停止确认成功后保留串口连接，取消的任务不会自动续跑**。

## 第一次打开

1. 下载仓库 ZIP 并**完整解压**，或用 Git 克隆本仓库。
2. 安装 Python 3.10 或更新版本，推荐 Python 3.12。串口库 pyserial 3.5 已附在 `program/vendor/` 中。
3. 双击 [`program/start_windows.bat`](program/start_windows.bat)，保留弹出的命令窗口。
4. 浏览器会打开 **http://127.0.0.1:8765/**。如果已有控制程序运行，直接使用原网页；同一套仪器只开一个服务。
5. 网页默认自动寻找 CH340，点击“连接”。有多个适配器时手动选仪器所在端口。串口号以本次识别结果为准，不固定为 COM5 或 COM6。
6. 先查看当前阀位和泵状态，再选择清洗、吹扫、称重向导或单步操作。

也可在 `program` 目录运行：

```powershell
python server.py --open-browser
```

运行数据保存在 `program/data/`，首次运行时自动创建。升级前自行备份此目录；仓库不包含本机运行日志、图像和个人配置。网页显示的是指令与设备读回状态，不能替代液体到达位置的现场观察。停止操作请使用网页“立即停止”或仪器本地停止；关闭网页不等于停泵。“立即停止”与“断开设备”分开；只有停止状态确认成功才显示连接保留，通信失败不会假报已停止。

## 当前接管与通信

| 项目 | 配置 |
| --- | --- |
| 泵 | LM60A，YZ1515 三滚轮泵头，设备地址 1 |
| 阀 | SV07M-20P 十六路，设备地址 2 |
| 总线 | 同一条 RS485，CH340 USB 转换器，9600 / 8N1 |
| 阀 1—6 | 六个样品瓶，PTFE 内径 1.6 / 外径 3.2 mm，各 50 cm |
| 阀 11—14 | 四个母液来源，14 为 PEG；PTFE 各 80 cm |
| 阀 15 | 清水，PTFE 80 cm |
| 阀 16 | 清洁空气入口；7—10 不使用 |
| 公共软管 | 同一根 16# 硅胶管，内径 3.2 / 外径 6.4 mm；A=10、B=10、C=71 cm，共 91 cm |
| C 端 | 悬空通向废液瓶上方，保持清洁，避开废液飞溅，不浸入液体 |
| 成像 | 一台相机、一块背光板，六瓶一排 |

本机装管方向已观察为：**CCW 从来源抽向废液；CW 向样品追送**。16 口吹扫沿 CCW，将公共管中残液排向 C 端；向样品反向追送时，空气从悬空 C 端吸入。重新装管后不能只凭 CW/CCW 字样判断实际流向。

## 网页可以做什么

- **手动泵阀控制：** 同屏显示阀位、泵状态、方向、流向和读回时间；选择阀口、CW/CCW、转速及整数圈数。可单独切阀、刷新状态、运行或停止；修改输入本身不会动作。
- **指定毫升：** 选择来源 11—15、目标瓶 1—6 及体积，每次只吸取一次、追送一次，再从 16 口向 C 端废液吹扫，不追加样品混合吹气。全部液体加完后再点“全部加完，向所选瓶吹气混合”。空气追送末端仍可能出现气泡。
- **自由单步与队列：** 可独立运行引液、吸取、追送、鼓泡、清洗和排水，也可组合操作；不要求先完成预充、观察或校准。仍需真实连接，动作串行执行，参数须有效且动作有结束时间。
- **来源预充与收尾：** 所选来源支管各 6 圈 / 50 rpm，然后直接 16 口吹扫。收尾流程不再等待搬管弹窗，须在点击前按页面说明摆好管端；动作结束不会被记作已完全排空。
- **可选校准：** 默认保存 45 步对应 0.15 mL 的清水参考，仍可重新称重校准；清水向导第 1、3 步可以跳过。校准不是自由调试的前提。
- **状态与图像：** 显示设备读回阀位及运行状态；逐瓶记录停气、消泡和静置信息，采集图像并保存人工判相标签。调试成像可直接开始，缺少的时间保持未知，不伪造静置完成。

手动圈数为 1—100 的整数、转速为 0.1—100 rpm；程序计算的动作超时须不超过 120 秒，否则在运动前拒绝。方向来自已接受的运动指令，不能通过查询推断仪器面板另行更改的方向。手动台允许向来源反送和从样品抽取，须自行确认实际管端位置。

基本液路顺序是：来源硬管先引液充满 → 公共管排去连续液柱 → 吸取目标液段 → 停泵切到样品 → 反转追送 → 按需要短时鼓泡 → 停气、消泡、静置成像。不能假定每轮之后自动恢复为空管；换母液时还需相应清洗与残水验证。

## 当前默认参数与证据边界

| 动作或参考 | 已保存的内容 | 如何理解 |
| --- | --- | --- |
| 来源硬管预充 | 所选来源各 6 原生圈 / 50 rpm，然后 16 口吹扫 | 每个来源理论纯转动 7.2 s；这是本次采用的预设，不代表已验证每种母液都能充满 |
| 称重向导 15 口灌管 | 当前自由调试为 6 原生圈 / 50 rpm | 只灌管，不自动吹扫；可手动跳过。历史 20 圈记录不代表当前 6 圈已验证 |
| 常规 15 口清洗 | 16 原生圈 / 50 rpm | 理论纯转动 19.2 s；不代表清洗残留已合格 |
| 16 口排水 | 15 原生圈 / 60 rpm | 理论纯转动 15 s；已有无连续水柱、无明显悬滴及飞溅的现场观察 |
| C 端充水参考 | 每 5 圈净质量 4.61、4.55、4.57 g | 按水密度 1.000 g/mL 近似为 0.915333 mL/圈；不是样品端交付系数 |
| 当前 1 号瓶入瓶参考 | 吸取 45 步 / 5 rpm；追送 1000 步 / 15 rpm | 用户报告单剂实际约 0.15 mL；作为当前比例估算，不代表重复性已验证 |
| 历史入瓶记录 | 一组 5 剂共 1.02 g，近似平均 0.204 mL/剂 | 保留为历史记录，已由当前 0.15 mL 参考替代 |

指定体积的默认换算：吸取步数 = 四舍五入（目标 mL × 300）；追送步数 = 1000 + max(0，吸取步数 − 45)。例如 0.5 mL 一次吸取 150 步、追送 1105 步；1.0 mL 一次吸取 300 步、追送 1255 步。默认吸取 5 rpm、追送 15 rpm，随后 16 口吹扫 15 圈 / 60 rpm。最终额外混合单独点击，默认 20 步 / 5 rpm，可调整。

这只是按已有单剂参考放大的工程起点。A 段几何容积约 0.804 mL，大液段可能进入泵头或 C 段；增加的追送步数和最终回收量尚需实测。程序记录请求量、估算量和执行步数，**不把估算量当作实际交付量**。

步数动作和原生圈数动作不是可随意互换的单位。实际过程还包括切阀、通信和等待，不能把上表纯转动时间当作整套动作时长。校准必须在最终样品出口收集并称量，不能只使用 C 端出液量推算。

**尚未完成的实机验证：** 切入样品瓶时的瞬间回吸原因、单剂重复性、按比例放大的单次加料回收量、真实母液回收量、清洗残水、交叉污染、鼓泡充分性和可靠判相等待时间。0.15 mL 参考不能证明重复性，也不能直接作为 PEG 的准确系数。自动化软件测试不证明物理配液精度。

## 开发与测试

从仓库根目录运行：

```powershell
cd program
python -m unittest discover -s tests -v
```

测试使用隔离目录和假硬件，不打开真实串口。GitHub Actions 在 Windows / Python 3.12 上执行相同测试。

可选浏览器测试需要 Node.js、Playwright 和标准位置安装的 Microsoft Edge。操作见 [`program/tests/browser/说明.txt`](program/tests/browser/说明.txt)。测试使用专用假服务端口 8879 或随机本地端口，不要将浏览器测试指向控制实物的 8765 服务。

```text
program/                   程序、网页、默认配置和测试
  static/                  前端界面
  tests/                   隔离软件测试
  vendor/                  随附 pyserial
  data/                    本机运行后生成，不纳入 Git
docs/reference/            交付参考文档与图纸
docs/templates/            空白实验记录表
.github/workflows/         自动测试配置
```

第三方组件说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。本仓库暂未为自有代码指定开源许可证。
