# 双水相配液与图像记录平台

[![Windows tests](https://github.com/Shih-y/atps-automation/actions/workflows/tests.yml/badge.svg)](https://github.com/Shih-y/atps-automation/actions/workflows/tests.yml)

通过本地网页控制润泽 LM60A 蠕动泵和 SV07M-20P 十六路切换阀，用于双水相配液、清水称重校准、逐瓶鼓泡以及图像采集和判相记录。

本仓库从 2026-11-11 的实机交付版本整理而来。默认使用真实设备；软件测试中的替身只用于测试，不是网页的模拟模式。启动程序和点击连接都不会自动转泵。

## 第一次打开

1. 下载仓库 ZIP 并**完整解压**，或用 Git 克隆本仓库。
2. 安装 Python 3.10 或更新版本，推荐 Python 3.12。串口库 pyserial 3.5 已附在 `program/vendor/` 中。
3. 双击 [`program/start_windows.bat`](program/start_windows.bat)，保留弹出的命令窗口。
4. 浏览器会打开 **http://127.0.0.1:8765/**。如果已有控制程序运行，直接使用原网页；同一套仪器只开一个服务。
5. 网页默认自动寻找 CH340，点击“连接”。有多个适配器时手动选仪器所在端口。串口号以本次识别结果为准，不固定为 COM5 或 COM6。
6. 先查看当前阀位和泵状态，再选择清洗、吹扫、称重向导或单步操作。

也可在 `program` 目录运行：

```powershell
python server.py --open-browser
```

运行数据保存在 `program/data/`，首次运行时自动创建。升级前自行备份此目录；仓库不包含本机运行日志、图像和个人配置。网页显示的是指令与设备读回状态，不能替代液体到达位置的现场观察。停止操作请使用网页“立即停止”或仪器本地停止；关闭网页不等于停泵。

## 当前接管与通信

| 项目 | 配置 |
| --- | --- |
| 泵 | LM60A，YZ1515 三滚轮泵头，设备地址 1 |
| 阀 | SV07M-20P 十六路，设备地址 2 |
| 总线 | 同一条 RS485，CH340 USB 转换器，9600 / 8N1 |
| 阀 1—6 | 六个样品瓶，PTFE 内径 1.6 / 外径 3.2 mm，各 50 cm |
| 阀 11—14 | 四个母液来源，14 为 PEG；PTFE 各 80 cm |
| 阀 15 | 清水，PTFE 80 cm |
| 阀 16 | 清洁空气入口；7—10 不使用 |
| 公共软管 | 同一根 16# 硅胶管，内径 3.2 / 外径 6.4 mm；A=10、B=10、C=71 cm，共 91 cm |
| C 端 | 悬空通向废液瓶上方，保持清洁，避开废液飞溅，不浸入液体 |
| 成像 | 一台相机、一块背光板，六瓶一排 |

本机装管方向已观察为：**CCW 从来源抽向废液；CW 向样品追送**。16 口吹扫沿 CCW，将公共管中残液排向 C 端；向样品反向追送时，空气从悬空 C 端吸入。重新装管后不能只凭 CW/CCW 字样判断实际流向。

## 网页可以做什么

- **单步操作：** 切阀、有限步数或圈数转泵、来源引液、清洗、空气排水、吸取液段、追送和鼓泡。
- **组合操作：** 清水清洗与吹扫，单剂试送，以及五剂一组称重；半自动操作在需要观察时等待确认。
- **自动队列：** 使用与液体、管路、样品瓶和动作参数匹配的已验证档案。初始正式档案为空，不把清水参考自动当作母液档案。
- **校准：** 内置已测清水参考，仍可选重新校准；清水向导第 1、3 步可在相应管路状态已经满足时手动跳过。
- **状态与图像：** 显示指令方向、运行状态、剩余步数/圈数、读回阀位；逐瓶记录停气和静置时间，采集图像并保存判相标签。

基本液路顺序是：来源硬管先引液充满 → 公共管排去连续液柱 → 吸取目标液段 → 停泵切到样品 → 反转追送 → 按需要短时鼓泡 → 停气、消泡、静置成像。不能假定每轮之后自动恢复为空管；换母液时还需相应清洗与残水验证。

## 当前默认参数与证据边界

| 动作或参考 | 已保存的内容 | 如何理解 |
| --- | --- | --- |
| 首次 15 口灌管 | 20 原生圈 / 50 rpm | 理论纯转动 24 s；已有一次到 C 端连续出水的实机观察 |
| 常规 15 口清洗 | 16 原生圈 / 50 rpm | 理论纯转动 19.2 s；不代表清洗残留已合格 |
| 16 口排水 | 15 原生圈 / 60 rpm | 理论纯转动 15 s；已有无连续水柱、无明显悬滴及飞溅的现场观察 |
| C 端充水参考 | 每 5 圈净质量 4.61、4.55、4.57 g | 按水密度 1.000 g/mL 近似为 0.915333 mL/圈；不是样品端交付系数 |
| 1 号瓶入瓶参考 | 吸取 45 步 / 5 rpm；追送 1000 步 / 15 rpm | 一组 5 剂共 1.02 g，近似平均 0.204 mL/剂；仅一组 |

步数动作和原生圈数动作不是可随意互换的单位。实际过程还包括切阀、通信和等待，不能把上表纯转动时间当作整套动作时长。校准必须在最终样品出口收集并称量，不能只使用 C 端出液量推算。

**尚未完成的实机验证：** 切入样品瓶时的瞬间回吸原因、单剂重复性、真实母液回收量、清洗残水、交叉污染、鼓泡充分性和可靠判相等待时间。已有 1.02 g 数据不能证明每剂准确 0.20 mL，也不能直接用于 PEG。自动化软件测试不证明物理配液精度。

## 开发与测试

从仓库根目录运行：

```powershell
cd program
python -m unittest discover -s tests -v
```

测试使用隔离目录和假硬件，不打开真实串口。GitHub Actions 在 Windows / Python 3.12 上执行相同测试。

可选浏览器测试需要 Node.js、Playwright 和标准位置安装的 Microsoft Edge。操作见 [`program/tests/browser/说明.txt`](program/tests/browser/说明.txt)。测试使用专用假服务端口 8879 或随机本地端口，不要将浏览器测试指向控制实物的 8765 服务。

```text
program/                   程序、网页、默认配置和测试
  static/                  前端界面
  tests/                   隔离软件测试
  vendor/                  随附 pyserial
  data/                    本机运行后生成，不纳入 Git
docs/reference/            交付参考文档与图纸
docs/templates/            空白实验记录表
.github/workflows/         自动测试配置
```

第三方组件说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。本仓库暂未为自有代码指定开源许可证。
