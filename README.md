## 打开程序

1. 下载仓库并完整解压，或克隆仓库。安装 Python 3.10 及以上版本，推荐3.12。
2. 双击 [program/start_windows.bat](program/start_windows.bat)，或进入`program`执行`python server.py --open-browser`。
3. 浏览器访问 `http://127.0.0.1:8765/`。同一套仪器只运行一个控制服务。
4. 点击连接，自动识别唯一CH340；多个适配器时手动选择。泵和阀共享一个串口。

串口库pyserial 3.5随附在`program/vendor/`。运行记录和校准保存在`program/data/`，不上传GitHub。更新前保留原运行数据。已启动的旧服务须在结束实验、允许断开时重启，才能使用新后端；本次发布不会自行重启服务或移动液体。

## 一瓶的操作顺序

1. 将使用的来源管浸入对应液体并选择预充。默认每口6圈、50 rpm，全部所选来源完成后做16口吹扫。
2. 旧手动mL调试可选择目标样品瓶，填写10—15口各自需要的毫升数；不用的来源填0。正式质量配样使用“实验设计”，按上方新操作说明进行。
3. 启动组合加料。程序先检查整份配方，再逐个来源吸取、反向追送。
4. 手动mL配方每来源一次吸取、一次追送，取消0.8 mL自动拆段；超出有限动作时间或来源标定范围时，整份配方不启动。
5. **各段、各来源之间不清洗、不弃液复位、不做16口吹扫。** 空气反向追送仍是入瓶的必要动作，末端可能出现气泡。
6. 手动组合配方全部加完后，自动向本瓶吹气混合，再切15口引入约1.5 mL水朝C端废液方向清洗，不做末尾空气吹扫。混合默认20步、5 rpm，可调整。公共管仍湿，不表示洗净或排空；正式自动质量实验保留项目冻结的方法。

旧清水组合试验和重复调试区已从默认页面移除。单步清洗、吹扫仍可独立使用。来源/样品管收尾仅处理所选管路，点击前按页面说明放好管端，不再等待搬管确认。

## 手动控制和校准

- 同屏查看阀位、泵状态、方向、rpm和读回时间。手动选择阀口、CW/CCW、转速及整数圈数，可单独切阀或运行。
- CCW：阀口经泵到C端废液。CW：C端经泵送向所选阀口。顶部手动台允许两种方向。
- 立即停止取消当前任务，读回确认停机后保留串口连接，旧任务不会续跑。断开设备是独立操作。
- 按钮没有预充、校准、现场观察等前序锁定。断开、非法参数或忙碌时显示原因，不将重复点击暗中排入运动队列。
- 当前调试默认 **45步/5 rpm吸取、2000步/30 rpm基础追送**。0.15 mL是旧1000步/15 rpm追送条件下的用户报告，仍仅作吸取步数估算；新追送条件的交付量须复测。可重新试送、称量并保存新参考。正式质量实验按每个来源冻结的标定参数执行，不自动追认新的转速。
- 0.01 g天平可用5剂总量求平均。当前参考不能证明单剂重复性或母液准确度。C端每圈出水量不是样品端交付系数。

已保存分来源体积参考时，按该来源的mL/步和瓶位适用范围换算，追送使用参考中的固定参数；单点测量外的比例缩放明确标为试用。没有分来源参考时，PEG14口暂按300步实收0.42 mL计算，1 mL约714步，追送30圈/60 rpm；其他来源仍用旧清水参考估算。PEG新追送和一次吸取未验证；大液段可能超过A段容量进入泵头，末尾清洗残水和中间不清洗的交叉污染均须实测。没有实测依据时不声称准确交付。

## 摄像头与判相

本机摄像头默认关闭，只在点击打开后请求权限，画面不镜像。瓶号按画面**右到左1—5**。液路仍可操作1—6口，默认图像布置只有1—5号瓶。

浏览器本地分析像素，尝试定位瓶子和搜索液体内部水平界面。定位不清时可手工修正ROI，也可保存原图并记录尚未定位的瓶号。原图、ROI、算法版本和候选结果会存档；人工判相标签另存。

算法为可检查的光学启发式，尚无本装置实拍数据集准确率验证。反光、气泡、低对比度、运动或无法可靠定位时保留不确定。候选单相只表示没有发现可信界面，不能排除低对比度双水相；不承诺30秒判相。摄像头和图像保存不要求连接泵阀。

### 构建 Windows 桌面版

```powershell
cd program
python -m pip install -r requirements.txt -r requirements-desktop.txt
python build_windows.py --onedir
```

目录版输出到 `program/dist/ATPS-Automation/`。推荐下载 Windows ZIP 并完整解压，双击其中的 `ATPS-Automation.exe`，保留同目录下的 `_internal` 和 `.exe.config`。目录版省去每次启动时的临时解包。单文件版仍可通过 `python build_windows.py` 构建，输出到 `program/dist/`，使用时须把同名 `.exe.config` 放在旁边。

桌面日志 `%LOCALAPPDATA%\ATPS-Automation\data\desktop.log` 记录本地服务、窗口、WebView2 和页面加载的启动时间点。`build_info.json` 记录源码提交号。推送 tag 会触发 `.github/workflows/release.yml`，运行后端、判相及浏览器回归，并验收单文件版和从发布 ZIP 解压出的目录版。

本次修复增加数据库异常下优先停止、按项目冻结批次、统一采用组成、延迟人工复核、严格限定项目导出及结构化训练资格。旧数据库升级前自动备份；旧标定保留为试用，不追认实验精度。六页前端已拆为独立模块，所有保存操作支持幂等重试。
