# 双水相配液与图像判相平台

[![Windows tests](https://github.com/Shih-y/atps-automation/actions/workflows/tests.yml/badge.svg)](https://github.com/Shih-y/atps-automation/actions/workflows/tests.yml)

2026-11-13 版本依据用户 Excel 建议更新：一次填写一瓶的各来源加料量，分段吸取追送，全部加完后自动混合，最后只做一次16口吹扫。页面保留泵阀手动控制、清洗、管路预充和排液、可选校准，以及本机摄像头的瓶子定位和候选判相。

程序只控制真实仪器，没有用户模拟模式。启动和连接不会自动转泵。软件测试使用隔离替身，不连接仪器。

## 打开程序

1. 下载仓库并完整解压，或克隆仓库。安装 Python 3.10 及以上版本，推荐3.12。
2. 双击 [program/start_windows.bat](program/start_windows.bat)，或进入`program`执行`python server.py --open-browser`。
3. 浏览器访问 `http://127.0.0.1:8765/`。同一套仪器只运行一个控制服务。
4. 点击连接，自动识别唯一CH340；多个适配器时手动选择。泵和阀共享一个串口。

串口库pyserial 3.5随附在`program/vendor/`。运行记录和校准保存在`program/data/`，不上传GitHub。更新前保留原运行数据。已启动的旧服务须在结束实验、允许断开时重启，才能使用新后端；本次发布不会自行重启服务或移动液体。

## 一瓶的操作顺序

1. 将使用的来源管浸入对应液体并选择预充。默认每口6圈、50 rpm，全部所选来源完成后做16口吹扫。
2. 选择目标样品瓶，一次填入11—15口各自需要的毫升数；不用的来源填0。
3. 启动组合加料。程序先检查整份配方，再逐个来源吸取、反向追送。
4. 单一来源超过0.8 mL时分段；超过1.6 mL可分更多段，每段名义量不超过0.8 mL。分段保持整数步数总量。
5. **各段、各来源之间不清洗、不弃液复位、不做16口吹扫。** 空气反向追送仍是入瓶的必要动作，末端可能出现气泡。
6. 本瓶全部加完后，自动向本瓶吹气混合，再切16口向C端废液吹扫。混合默认20步、5 rpm，可调整。

旧清水组合试验和重复调试区已从默认页面移除。单步清洗、吹扫仍可独立使用。来源/样品管收尾仅处理所选管路，点击前按页面说明放好管端，不再等待搬管确认。

## 手动控制和校准

- 同屏查看阀位、泵状态、方向、rpm和读回时间。手动选择阀口、CW/CCW、转速及整数圈数，可单独切阀或运行。
- CCW：阀口经泵到C端废液。CW：C端经泵送向所选阀口。顶部手动台允许两种方向。
- 立即停止取消当前任务，读回确认停机后保留串口连接，旧任务不会续跑。断开设备是独立操作。
- 按钮没有预充、校准、现场观察等前序锁定。断开、非法参数或忙碌时显示原因，不将重复点击暗中排入运动队列。
- 默认参考为 **45步/5 rpm吸取、1000步/15 rpm追送，用户报告单剂0.15 mL**。可重新试送、称量，填写平均每剂毫升数及对应动作参数并保存。后续配方读取新参考。
- 0.01 g天平可用5剂总量求平均。当前参考不能证明单剂重复性或母液准确度。C端每圈出水量不是样品端交付系数。

每段吸取量按保存的每剂参考换算。追送使用原追送基数加上本段比原参考多吸取的步数。这一扩展规则、分段上限及中间不清洗的残留/交叉污染均需实测。0.8 mL是样品端参考推算的名义上限，不能证明A段实际液塞不会进入泵头。

## 摄像头与判相

本机摄像头默认关闭，只在点击打开后请求权限，画面不镜像。瓶号按画面**右到左1—5**。液路仍可操作1—6口，默认图像布置只有1—5号瓶。

浏览器本地分析像素，尝试定位瓶子和搜索液体内部水平界面。定位不清时可手工修正ROI，也可保存原图并记录尚未定位的瓶号。原图、ROI、算法版本和候选结果会存档；人工判相标签另存。

算法为可检查的光学启发式，尚无本装置实拍数据集准确率验证。反光、气泡、低对比度、运动或无法可靠定位时保留不确定。候选单相只表示没有发现可信界面，不能排除低对比度双水相；不承诺30秒判相。摄像头和图像保存不要求连接泵阀。

## 接管和通信

| 项目 | 当前配置 |
| --- | --- |
| 泵 | LM60A、YZ1515三滚轮，设备地址1 |
| 阀 | SV07M-20P十六路，设备地址2 |
| 通信 | 共用RS485，CH340自动识别，9600 / 8N1 |
| 1—6口 | 样品PTFE支管，内径1.6 / 外径3.2 mm，各50 cm |
| 11—14口 | 母液来源，14为PEG；PTFE各80 cm |
| 15口 | 清水，PTFE 80 cm |
| 16口 | 清洁空气；7—10不用 |
| 公共管 | 连续16#硅胶管，内径3.2 / 外径6.4 mm；A10、B10、C71 cm |
| C端 | 悬空通向废液，不浸液，保持清洁、避开飞溅；反向时也从这里吸气 |
